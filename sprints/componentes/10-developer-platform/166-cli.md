# FiscalUI Framework

## Documento 166 — CLI

**Nível 10 — Developer Platform**

**Versão 1.0**

Interface de linha de comando para criar, gerenciar, testar e publicar projetos FiscalUI.

---

```bash
# Instalação global
npm install -g @fiscalui/cli

# Comandos principais
fiscalui new <project-name>     # Cria novo projeto
fiscalui generate <type> <name> # Gera componente/theme/plugin
fiscalui serve                  # Servidor de desenvolvimento
fiscalui build                  # Build de produção
fiscalui test                   # Executa testes
fiscalui publish                # Publica no Marketplace
fiscalui upgrade                # Upgrade de versão
fiscalui doctor                 # Diagnóstico do ambiente
fiscalui init                   # Inicializa config no projeto existente

# Flags comuns
--template      # Template inicial (default, blank, enterprise)
--typescript    # Habilita TypeScript
--strict        # Modo estrito (lint + types)
--skip-install  # Pula npm install
# -y              # Confirma automático
```
