# FiscalUI Framework

## Documento 023 — Floating Action Button

**Nível 2 — Basic Components**

**Versão 1.0**

Botão flutuante para ação principal da tela. Posicionado no canto inferior direito, elevado sobre o conteúdo.

---

```js
class UIFAB extends UIComponent {
    constructor(options = {}) {
        super(options);
        this.icon = options.icon || 'plus';
        this.label = options.label || '';
        this.size = options.size || 'md';
        this.onClick = options.onClick || null;
    }

    template() {
        return `
            <button class="ui-fab ui-fab--${this.size}"
                    type="button"
                    aria-label="${this.label || this.icon}">
                ${FiscalUI.icons.render(this.icon, { size: this._iconSize() })}
                ${this.label ? `<span class="ui-fab__label">${this.label}</span>` : ''}
            </button>
        `;
    }

    _iconSize() { return this.size === 'sm' ? 20 : 24; }

    onInit() {
        this.element.addEventListener('click', (e) => {
            this.emit('fab:click', { originalEvent: e });
            this.onClick?.(e);
        });
    }
}
```
